# Savings

A simple salary savings calculator. Enter your fixed salary and the app computes how much you save.

## How to run

Open `index.html` in a browser. No dependencies, no build step.

## Files

- `index.html` — the calculator UI
- `style.css` — styling
- `index.js` — calculation logic
